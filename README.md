## How I Work

- **Truth before claims:** features, prices, results, and publication status must be evidence-based.
- **English for public documentation:** repository-facing guides and project documentation use clear English.
- **GitHub-first workflow:** inspect, plan, work on a feature branch, review changes, test, and open a pull request.
- **Human ownership:** I retain control of merges, publishing, deployments, and external decisions.
- **Privacy and security:** credentials stay in approved secret stores; private contact details are not published in repository documentation.
- **Free-tier awareness:** I prefer free tools and tiers where practical. Provider limits and terms can change, so “free” is never treated as an unlimited guarantee.
