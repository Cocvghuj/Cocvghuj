## Mirror, Backup & Ownership Rules

- Personal and organization accounts are separate GitHub owners with separate permissions; they cannot become one account through README changes.
- Keep one canonical source repository for each TRTT-owned project. Use forks or backup branches for mirrors; do not create competing copies with unclear ownership.
- Preserve upstream fork identity, original license notices, attribution, tags, and upstream synchronization.
- Do not force-push, overwrite upstream work, or merge a pull request without the Owner.
- GitLab backup branches are separate from GitHub organization forks. Verify branch commit IDs and file content before reporting a mirror as synchronized.
- Private repositories and private operational records are intentionally excluded from this public directory.
